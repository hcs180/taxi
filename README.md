# taxi｜長者、司機、家屬三端互動展示版

這是 **GitHub Pages 專用的靜態網站**，可直接點開操作，不需要 PHP、Node.js、MySQL 或 Google Maps API 金鑰。

## 快速展示

1. 打開網站首頁，選「回診」→「新增回診」。
2. 在醫院地址欄可 **自行輸入**，或點「選擇附近醫院」。列表預先提供三間苗栗院所範例；點「使用目前位置」會經瀏覽器授權向 OpenStreetMap Overpass 查詢附近院所（需要外部網路，可能受第三方服務狀態限制）。
3. 在首頁選「我要去醫院」，輸入上下車位置、時間並按「儲存用車規劃」。網頁立即顯示 **示範** 車牌 `ABC-7283`、銀白色與預估到達分鐘數。可以返回、縮小詳細資訊、取消叫車，也能在此頁按「分享本次位置給家屬畫面」並自行授權定位。
4. 在長者端「設定」最下方點「切換到司機介面」。有展示叫車安排時，地圖自動縮小並顯示乘客位置欄位和提醒備註。可依序點「已到達上車地點」、「乘客已上車」、「抵達目的地」。
5. 切回長者端，在「回診」可依序標記「已抵達醫院」、「已完成報到」、「正在候診」、「看診完成」。之後從「設定」切換到家屬介面，查看進度數線、Google 地圖與情境提醒。
6. 長者端字體維持「一般／大／特大／超大」，司機、家屬端則各自獨立記住「小 20pt／中 26pt／大 32pt」。字體提示僅顯示 1.2 秒。

## 角色功能與資料更新

| 模組 | 展示功能 | 更新方式 |
| --- | --- | --- |
| 長者 | 回診管理、附近醫院選單、自由輸入、叫車畫面、車牌、車色、預估到達、取消與返回 | 操作後立即更新 |
| 司機 | Google 地圖、附近示範熱度、接單後縮小地圖、乘客位置與備註、行程階段操作 | 熱度按 15 分鐘時間區間重新產生；每 30 秒檢查是否跨入下一個區間 |
| 家屬 | 看診進度數線、目前院所或自願分享的位置、關懷提醒 | 每 3 分鐘重新讀取此瀏覽器資料，亦可手動更新 |

**重要：這只是展示版。** 車牌、車色、到達分鐘數、叫車熱度、接單階段均是 **範例／由使用者按鈕更新的展示資料**，不是即時車隊 API。家庭端無法在另一台手機上接收行程狀態；資料存於同一瀏覽器的 `localStorage`。不會真的建立計程車訂單、派車、聯絡醫院、推送通知、預測醫療結果，或自動追蹤長者 GPS。

「分享本次位置」是選擇性操作，會要求定位權限並把當次座標存入本機瀏覽器供同裝置家屬畫面展示；地圖載入時可能將查詢地點提供給 Google。為避免暴露個資，請只輸入虛構地址與人物資料。本專案沒有處理任何正式病歷資訊。

### Google 地圖與醫院搜尋的限制

本版使用 Google Maps 網頁嵌入 (`maps.google.com/maps?output=embed`) 並提供「在 Google 地圖開啟」連結作為備援。此方式不需金鑰，但不是官方 Maps Embed API 的保證整合方式，嵌入在部分瀏覽器或網路政策環境可能被阻擋。Google 官方 Maps Embed API 需要 Google Cloud API 金鑰與帳單設定。若部署正式服務，應改用受支持的 Google Maps Platform API。

Google Maps 舊 `HeatmapLayer` 已在 2026 年停止支援，因此本展示版用 **Google 地圖 + 可點選的區域熱度清單** 表現概念，並非真正的地理熱度圖。實際 15 分鐘需求熱點需有經同意的車隊訂單數據與後端。

附近醫院選單預設提供衛福部苗栗醫院、大千綜合醫院、為恭紀念醫院；定位搜尋由 OpenStreetMap Overpass 第三方服務回傳，資料可能不完整。若第三方服務不可用，可繼續選擇預設院所或自由輸入。預設清單不代表系統已確認「附近」距離。

## GitHub Pages 部署

上傳以下內容到公開 Repository 的 **根目錄**：

```text
taxi-three-role-demo/
├── index.html
├── assets/
│   ├── app.js
│   └── style.css
├── .nojekyll
└── README.md
```

在 **Settings → Pages → Build and deployment** 選擇 `Deploy from a branch`，指定 `main` 和 `/(root)`。網站通常會位於：

`https://你的GitHub帳號.github.io/你的Repository名稱/`

不需要部署舊版的 `index.php`、`state_process.php`、資料庫或 `.htaccess`。本版本保留上一版 `localStorage` 儲存鍵值，既有回診記錄與長者字體偏好會在相同瀏覽器延續。

## 真正營運所缺的東西

若日後要變成可正式使用的計程車與長者就醫服務，需要會員與權限分離、正式 API 與資料庫、即時位置授權及撤銷、車隊接單與 ETA、醫療端合法提供的就診階段資料、伺服器排程與 15 分鐘熱區聚合、家屬通知推送、個資保護及無障礙實際使用者測試。這些功能無法單靠 GitHub Pages 提供。
